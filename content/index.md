## Prof's M-level template for concept answers

For Part I-B Option 1 (10 of these out of the 35 study-sheet concepts), each answer should be 3–5 sentences hitting:

1. **Source attribution** — author, article/book title, with page or reading-link reference where possible
2. **Core definition** — in the source's own register, not a loose summary
3. **Key quotes or data** — the prof rewards exact phrasing
4. **Context** — why it matters historically/theoretically
5. **Film tie-in** — concrete example from a syllabus film, with the formal element identified

Each 🎯 concept note below is written in this template so you can lift sentences directly.
