# Lunacharsky's SR Definition

**Author:** Anatolii Lunacharsky (Commissar of Enlightenment, 1917–1929)
**Source:** Quoted in *Film Factory*, p. 327

## Definition
The clearest one-line definition of [[Socialist Realism]] / [[Modal Schizophrenia]]:

> "The Socialist Realist does not accept reality as reality is. He accepts it as it will be."

The artist's job is to represent the future as if it were already present.

## Films using it
- [[07 Volga-Volga]] — the prof's exam question explicitly asks: "can we call the director a true Socialist Realist?" using this Lunacharsky quote as the criterion

## Example
Volga-Volga's Moscow shines with utopian abundance in 1938 — Lunacharsky's principle in operation. The Moscow Aleksandrov films is "as it will be" (post-construction-of-communism Moscow), not "as it is" (1938 ration-card Moscow).
