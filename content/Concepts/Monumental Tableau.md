# Monumental Tableau

**Author:** Aleksandr Dovzhenko (style); concept generic in Soviet film criticism

## Definition
Dovzhenko's static-but-charged composition: bodies, landscape, and ritual frozen in painterly arrangement. Death, harvest, and birth as biological cycle. Critics accused Dovzhenko of "biologism" — reducing class struggle to nature.

## Films using it
- [[04 Earth]] — the foundational work

## Example
The grandfather's death under the apple tree in Earth: Dovzhenko frames the dying old man, the apple tree, the family in a static composition that reads as religious icon. The death is not narrative event but biological-spiritual ritual. Critics charged this with insufficient class analysis ("biologism"); admirers find it Dovzhenko's poetic signature.
