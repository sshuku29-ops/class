# Master Plot

**Author:** Katerina Clark
**Source:** *The Soviet Novel: History as Ritual* (1981)

## Definition
Every Stalinist novel rewrites the same story — spontaneous hero meets mentor, struggles, achieves consciousness, often dies for the cause. Ritualized, not narrative. The master plot is what makes [[Socialist Realism]] formally recognizable across thousands of works.

## Films using it
- [[06 Chapaev]] — the cinematic master plot's foundational instance
- All SR cinema (1934–1953) follows the template

## Example
The master plot has a fixed sequence: ordinary protagonist → first failure → encounter with party mentor → re-education → second test → consciousness → final sacrifice (often death). Chapaev hits every beat. Volga-Volga rewrites it as comedy. Fall of Berlin scales it up to epic.
